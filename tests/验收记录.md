# 《这辈子》v1.3 原型验收

依据 v1.3 产品文档第 3、4、8–11、14–16 节。当前实现有 46 个回合位和 99 张事件卡，首批包括 3 条隐藏梦想和 4 类普通职业。

## 自测覆盖

| 验收项 | 核对结果 |
| --- | --- |
| 完整人生与普通职业 | 从出生走完 46 回合，分别覆盖办公室、制造业、配送和环卫。普通人生可以自然收束，回忆录按事实生成。 |
| 三条梦想与多个高光 | 覆盖电竞夺冠与未夺冠后转行、清北录取与落榜、独立作品发布与停止。同一人生有清北和独立游戏两个高光，归档为一个终章。 |
| 两格日程与实物装箱 | 日程覆盖 8 个回合位。两格主安排会占满日程，一格主安排可再加一个行动。实际结算、经验带入后续风险回合、刷新草稿和拖放都已验证。搬家节点支持点选和拖放旧物，确认后才更新持有状态。 |
| 工作台、职业低谷与风险 | 安排卡可点击选择或触控拖放。预览显示机会的优先、延期和截止。走测防护与忽视的不同后果，确认晚触发的低谷仍有恢复选择，并保留已经发生的支出。 |
| 跨年物件与人物 | 走测台灯、掌机、作品的保留、收起、指定重用与回响。赠出或丢弃的物件继续留在履历里。人物失联、重新联系、离世后过滤及共同经历回响分别验证。 |
| 终章、分岔与存档 | 检查自然、开放式和提前谢幕，验证隐蔽触发与独立走测入口。分岔比对历史前缀和新结果，确认原档案保留，同树只发放一次基础自由点。 |
| 9:16 与操作 | Chrome 从本地文件测了 320×568、360×640、390×844、430×932 和 1366×768。舞台保持 9:16，回合操作固定在底部，设置和分岔弹窗留在舞台内。实际触控、鼠标、Enter、拖放、弹窗及刷新草稿通过。Mac 上的 WKWebView 也通过离线打开和台灯流程。 |
| 动画 | 3 份人物、7 份道具、4 份环境的 32×32 独立工程，运行时按逐帧时长播放。14 份源文件均由本机 Aseprite 打开并导出。Chrome 验证离线预览、逐帧播放、暂停和源文件链接。 |

另外用 2,000 个固定种子模拟完整人生，全部抵达终章。模拟覆盖 94 张事件卡，晚发低谷另有定向测试。剩余四张是当前专属职业卡会覆盖的通用回退。

## 复测入口

从 v1.3 原型目录运行。

    node tests/acceptance.cjs
    node tests/lifecycle.cjs
    node tests/portrait-browser.cjs

浏览器脚本使用临时 Chrome 配置。环境变量 CHROME_BIN 可指定可执行文件。

双击 [原型](../index.html) 或 [动画预览](../art/index.html) 可离线检查。设置中的独立走测入口可直接复验提前谢幕。随附日常、回忆录两段原型音乐及轻量交互音效，可在设置里开启。设置还可导出本机走测计数与回合用时。

## 待真机和试玩验证

微信开发者工具、手机真机的安全区、触感、低端性能、正式音频和 30–50 分钟单局节奏仍待实测。当前验收覆盖离线浏览器原型和像素动画工程。

## v1.3.1 复验（2026-11-18）

- 玩法与生命周期脚本通过，含四类普通职业、三条梦想、同历史重走、低谷、旧友重联，以及新加的床头限一件、同行／独自搬家、饭桌引用真实经历、拍留言册收到专属回复。
- Chrome 离线测试覆盖 320×568、360×640、390×844、430×932、1366×768 视口。触屏横滑物架与拖放、场景行动、饭局、保存纪念和分岔弹窗通过；浏览器实际生成并解码了纪念与分支两种 720×1280 PNG。
- 动画目录现有 17 份独立 Aseprite 工程。三份新增递物动画已由本机 Aseprite 打开导出，离线图集及预览链接通过检查。
- 文档核对覆盖全部 113 个二三级标题、19 条梦想原编号及附录 A–C；效果差异与验证范围见[本版对照表](../../../这辈子_v1.3.1原型实现效果差异表.md)。微信真机、真人首次理解与连续重玩感受仍待外部试玩。
