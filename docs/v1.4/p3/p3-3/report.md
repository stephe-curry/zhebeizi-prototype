## 修改范围

- 游戏入口与内容声明涉及 index.html、tests/guidance.html、content.js、dream-chapters.js、chapters.js 和 routes.js。新增工作身份包括 J05 程序员、J08 小学教师及外科团队医师。
- engine.js 与 save.js 处理学籍与工作竞争、合同收入、原岗停薪、金牌寄语及历史重新核验。app.js、audio.js、style.css 负责专属场景、结果与原创新曲试听。
- 美术增加 art/dream-places.aseprite、assets/dream-places.png、assets/dream-places.json 与 art/previews/dream-places.gif。场景、美术道具、动作、反馈可独立编辑。七个标签各有四帧，帧长依次为 180、120、160、260 毫秒。
- 新增 tests/p33.cjs、tests/p33-lives.cjs。tests/p32-lives.cjs、tests/p32-browser.cjs 和 tests/portrait-browser.cjs 复用原页面走测入口。export.cjs 依据本次 Chrome 收据生成覆盖表和逐局见证。
