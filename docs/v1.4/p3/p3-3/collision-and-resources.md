# 同一期怎样取舍

每槽最多两段时间，梦想与职业共用一个安排位置。预约、读书、陪家人和下班后的投入跟随当前主事件的工时与精力结算。正式按下确认前可撤回；时间超额、精力不足或付完本期生活支出后存款不足，整笔行动不会提交。

|交汇|玩家看得见的取舍|
|---|---|
|制造与跨栏|工厂整班占去余段，可提前改签半班。加练第四组会推迟测评，需另排恢复。错过第 29 槽的资格赛会失去本届参赛机会。|
|程序员与开源|在职公司工单需要出勤；公开版本可以利用其他职业的余段制作。在同一槽只能提交一个操作，取得公开授权才可共用贡献收据。|
|普通岗位与读医|入学交回原岗。第 23 槽仍能接受原有职业机会，也能保留学籍继续培养。接受岗位将中断未完成的全日制学程。|
|配送、演出与办公室、拍摄|有整班聘约时先调班。真正出席演出、群演、试镜和拍摄时会按当期安排记原岗停薪，合同酬劳另有来源。|
|城南、石桥与家访|一份班表只能属于当前任教安排。家访消耗可用时间，离开石桥后保留旧班册，后续学生行动要通过学校与日期核验。|
|租房与旅行|预订从积蓄支付，房租照计，取消保留已付费用。到访与返程暂停原岗工资；体力低于长途门槛须改期。|
|多个梦想与家庭|可并行确立和暂停多个梦想。同一期的歌手排练与演员试镜只能选一项，额外照护、亲友邀约与手记行动共同占用余段。|
