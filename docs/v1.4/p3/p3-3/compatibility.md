# 既有人生与档案回归

开发前的分支、HEAD、暂存区与工作树记录在 evidence/start.log。冻结副本保留了先前尚未提交的 P2、P3-1 与 P3-2 工作。本阶段以该副本作基线。

- Node 旧套件的 112 个测试和两项独立验收脚本通过。覆盖童年、礼物、商店、年夜饭、人生树、旧机会、选择时容量、同种子重放和专业路线。日志保留原脚本的历史名称与输出。
- Chrome 旧套件在正式页面检查多尺寸布局、输入与恢复、P2 事件和回响、P3-1 多梦想与隔离分支，以及 P3-2 的 18 段见证。开发前竖屏套件首次在饭桌离场等待超时；相同冻结副本重试通过。首次失败日志与复测日志分别保留。最终竖屏测试在切换系统减少动画模拟后等待两帧，让偏好变更引起的界面重绘完成，再发送同一个鼠标点击。
- 新行动作为回合事实保存。导入时通过历史前缀重新产生可用动作、资格、结果和工资，再核对来源。伪造署名会被拒绝；旧档中不存在新动作时无需补写经历。
- 第 23 槽全日制学生可明示继续上学；仍可选择原岗位或电竞邀请。原岗位继续保留原选择 ID。读医或师范后转岗会打断该次培养。
- 奥运寄语查实决赛金牌收据。电竞、独游、旧职业和其他梦想沿用各自原有高光、机会与寄语。
