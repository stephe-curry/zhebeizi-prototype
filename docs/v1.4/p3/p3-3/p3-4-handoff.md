# P3-4 职业制作交接

- **J05 程序员**已有公交信息公司聘约、半班与整班工资、公司站牌工单、独立公共项目、明确授权的适配器和离岗后维护。下一阶段补上线后的用户服务、需求变更、同事分工和职业中段转岗。保留个人维护者无须受聘的入口。
- **J08 小学教师**已有本科、试讲实习、资格、两所学校聘任、班级名册、真实课堂和调动。下一阶段补普通城市教师的多年备课、家校协作与带教。石桥班册只在实际赴乡后建立。
- **J04 小微经营**可沿用独立成本与履约收入。进货、存货、退单和家庭开销需要各自来源，营业额与个人收入应分别表示。
- **J06 公务员**可复用分期报名、资格、有限外因和实际聘任。具体公告、学历、年龄与岗位须按届次核对，录用后增加实际办件场景。
- **J07 厨师**可复用订单分步操作、核对与交接。补后厨班次、备料和退菜责任；员工工资、门店收款和原料成本分别结算。
- **P3-5 复验**优先跟踪工厂训练与临时轮班、配送晚高峰与演出、租约与跨洲旅费、城镇调动与家庭照护。普通职业在第 30–40 槽的独特工作行动密度仍需跨人生观察。P3-6 再做整版十八条路线联合验收。
