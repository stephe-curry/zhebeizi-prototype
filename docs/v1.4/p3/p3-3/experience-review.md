# 七个现场的内部体验审查

从当期手记选活动，进入具名场所，在原生对话框中操作，返回本期日程后统一提交。选择方法和提交付款是两个时点。320×568 下场景内部可以滚动；减少动画时保留最后一帧、步骤文本和结果。以下是开发审查，真人初见理解度与操作乐趣还需要实测。

|现场与动机|当下的操作和反馈|要舍弃什么，之后能看到什么|
|---|---|---|
|公共跑道，想知道为什么总在栏前碎步|找出步幅改变的位置，移起点或缩短头两步，得到不同首栏读数。加练会看到第四组变慢。|恢复占一段时间；带新人时可重画第一步。只有决赛金牌能触发专属寄语。|
|图书馆首站查不到|对照实际 -1 与预期 0，选择修复表达式，错误修复会显示两条失败输出，之后再按审查意见补同名站。|公司权限不能挪给个人；图书馆迁移与小禾贡献需要跨年积累。|
|病历夹的两页编号不一致|在模拟清点、带教实践和正式交班中分别复核数量、签名和编号，接班人复述待核事项。|学习占数年，离岗要停薪；真正回到团队须重新核验授权。|
|雨棚中的一句词|决定重音落在「雨」或「走」，可试听不同动机。与阿意重新起拍，录下有共同署名的第二版。|小场演出得到一次劳务费。场馆合同未履约时没有万人记录。可再回小厅唱双人版。|
|《渡口》的背景行人想要一个有名字的角色|对着妹妹袖口选择停顿，站到新机位的焦点，核对终剪。删角版仍有真实片酬。|公开网络发行会关闭此奖项窗口。后来接有偿围读或把时间留给家人。|
|石桥三班两根不一样长的纸条|裁出等长的整体，请阿苇再折。家访才得知小田为什么早走。|跨年再听阿苇讲题；小田可能随家人离开。调岗后不能继续以原班名义提交课堂。|
|车站票背上断开的两段线|选住宿预算，遇停运重接线路，核对准入材料，选择与当地人绘图或走访。|订金不可退，出发与返程消耗档期。家人能听到的故事取自实际到达过的地点。|

## 普通职业的内容密度

21 局中可见办公室、制造、配送等既有主事件持续出现；新手记占用的余段会挤掉主动职业行动。例如「雨棚·重拾」把配送后的多个余段给了创作和演出，职业侧以旧配送主事件为主。完整职业年表能留下工资和岗位变化，但连续多年出现工资不能说明玩家有连续多年的独特工作可玩。P3-5 需把同种子偏重职业、偏重梦想、兼顾家庭三种走法放在一起复验。
