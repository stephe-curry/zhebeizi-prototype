# 46 回合、多梦、职业与家庭的容量评估

## 当前测得的上限与不足

自动导出见 slot-capacity.generated.md / baseline.generated.json：46槽年龄固定；101卡是全局候选库而非每人生都出现。480种默认策略476满程、4提前；97张自然命中，合法改约可达101张。现有单槽只提交一张主卡；E.followups的draft.followup是单值，至多一项短回响，耗1精力。dayPlan另有一项extra，但仅主行动成本1时成立。主卡、extra与followup可以同槽并存，不能误写“46回合只能46次行动”，也不能把每个按钮当一段专业训练。

现有精力4/5/6，只在hotspot选择时计主事2或3，非hotspot主事used=0。精力不是全局真实日程容量；目前无法可靠阻止工作+十梦+家庭全部推进。所有新梦若只加C.cards会受固定slot与首张规则挤压，opportunityWindow本身不让卡跨槽出现。故“当前已支持十八条完整人生/多梦”不成立。

## 建议容量模型（P3待开发，非实测平衡）

沿用一主事+少量短行动。新活动适配槽有2段可支配叙事时间；常规新主事1，轻活动1，考试/全日训练/正式拍摄/跨国旅程2。新增side与dayExtra/followup共用余段，最多一项；精力/现金另查。家庭9/14/31/34若与主事同场只计一次；若实为另赴照护行程则占段，不能靠点对话免费完成照护。确立/暂停意向0段但不推进实践。

成年槽23–40共18槽，按模型有36段；维持18次普通生活/工作主事后最多18个额外轻行动。若给31与34各留独立家庭段，可用于额外梦的保守余量16。已有dayPlan主成本2必须保留，且旧P2回响会继续占用其中若干段；不能把16视为无条件可用训练。全日赛事等2段必须更换主事/请假，扣对应收入或失去当次业务。职业常态责任已反映在工资和工作安排，额外行动不能凭同槽主卡“没上班”就免费领满薪。

典型一梦可规划6–10个有意义投入/检验（含早年与后期），不要求每次新开主卡；晚起医学等需要更长实际年限。两梦可通过时间错开、共用合法作品/课堂与阶段接力共存。十梦同时持续高强度若每梦最低6次、另有18次职场与家庭，即远超可自由支配余量，且专业互斥；系统允许拥有十个愿望但不保证一生全高光。不能因此缩减十八条全局制作范围。

这仅是容量约束的工程设计；P3-1实现预算，P3-2/3/4用真实费用和活动后P3-5再跑模拟及Chrome。30–50分钟目标尚待真人验证；不把算式当可玩性结论。

## 可执行排程样本（待实现规则的可行性示例）

以下每槽安排均为新职业/课程场景的显式预算；不能套到旧主行动已占两段的dayPlan。

“程序员+开源+清北”在23–34槽的安排：23聘任主事1+接触开源1；24岗位1+复习1；25岗位1+补丁1；26岗位1+复习1；27请假考试2；28录取/入学2；29课程1+review1；30课程1+维护1；31学费/家庭主事1+课程安排1；32课程1+修复1；33学业项目2；34家人主事1+学位答辩安排1。毕业时长仍须由学段入学年龄核验：不能仅因槽34到来自动毕业。全日制期间若没有合法兼职安排就无J05工资；这说明共存的是跨阶段身份与目标，不保证一直满职领薪。

“教师+25+29”可用同一课堂同时服务J08与25；这是减少重复操作的合法共享，不是免费两次成长。首个乡校学期、家访和后续学生变化仍需不同年代的真实行为。安家在赴乡后的居住场景推进，不重复开三个确立弹窗。

## 理解成本与验收

只展示已接触候选与已确立目标；场景首屏保留一个具体行动目标。冲突时呈现两处去向、费用与可延日期，详情可展开，不把十梦同时铺满首屏。主专业操作后最多一项短事，轻场景1–2次有意义输入，重大选择用既有预览撤回。单局时长、晚年密度、首次玩家理解仍未证实。

P3-5应重放本表全部情境：同前缀选择A/B/不做，检查实际费用/收入/来源/窗口与晚年；排程超容必须在预览和提交都拒绝，不能只用UI禁用。输出“合法可达、真实已玩、资源拒绝、延期、未曝光关闭”分项统计。全局十八路线都可达与一局十八路线全达成是不同命题，本阶段只证明现有能力/缺口并给出可实现的安排。
