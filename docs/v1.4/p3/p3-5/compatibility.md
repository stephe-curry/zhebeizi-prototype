# 兼容与重放

本轮保留 46 槽、合法第 44 槽提前谢幕、已有主事件和选择 ID。复跑了 acceptance、lifecycle、童年礼物、购物与饭桌、引导、连续性、P2 历史种子及 P3-1 至 P3-4 全部现有 Node 专项。项目原有职业与梦想见证除了断言结局，还会用正式导入校验器重放收据与工资。

新增职业收据使用已有 schema 1。店款变动仅写入对应新动作的结果，旧档没有这些字段时余额由零开始。旧厨师转经营、文具、购食材与现卖动作维持原来的 ID、归属及金额。还保留原有作品、学生、物件所有状态、人物、聘约和命运检验种子。当前结算预检还会预留已签租约的当期房租。

玩家在本期明确谢绝后，草稿可记录 routeDeclined，结算记录可有 declined。老档缺少这些可选字段时照常读取。P3-5 备份含新状态时应由本阶段及后续兼容版本导入。真实 Chrome 备份通过设置页导出、再次导入并继续游戏；13 组分别复用同一分叉槽完整备份。另在 P3-1 页面回归检查真正的人生树父子分支隔离。

验证范围为仓库内历史用例、由正式引擎产生的样本和本轮导入导出。P3-6 应加入不同发布版本保留下来的真实玩家备份，尤其是旧厨房在经营中、已离岗、资格跨年及低谷草稿四类。
