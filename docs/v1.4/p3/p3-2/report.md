# 《这辈子》v1.4 · P3-2 工程交付

正式页面已接入三条梦想和三类普通职业。18 条浏览器人生从出生走完 46 槽，共 828 次主结算，覆盖六种出生身份。每一条都检查了终章、路线特有的结果及整档能否通过导入校验。

## 改动落点

新增 chapters.js 存放六条路线的专业条件、工作台材料与结果。routes.js 扩展了分步操作和来源重算；engine.js 接入岗位变更、学习、住房、物件布置与订单结算；save.js 核验步骤、收据和租约；app.js、style.css 和脚本入口接入工作台、即时反馈与回忆录。新增 P3-2 人生输入、Node 测试、Chrome 操作脚本和可重建报告。原 P3 浏览器脚本支持独立输出目录。

美术交付包括两个可编辑分层 Aseprite 文件、两套透明图集与逐帧 JSON、两份放大 GIF。life-desks 是六种职业／生活工作台的 24 帧原画，delivery-slip 是实际送达才播放的 8 帧蓝签动作。原手记动画继续用于其他行动。

## 实施口径与边界

本科和计算机硕士代表路径取北京大学，北京普通高考报名取京籍、满足高中毕业资格的情景。十八岁对应样例考年 2026；后来的考年随游戏年龄推进，使用锁定的制度样本。四年本科、三年学术硕士均按年龄差和实际学习材料核验。游戏没有模拟全部省份、专业、未来政策、真实分数线或每学期的全部课程。制造授权限于读数、记录和复检，设备维修由另有授权的工作人员执行。

此次验收为开发者内部检查、Node 与本机 Chrome 自动走测。移动端使用模拟视口，尚未开展 iOS／Android 真机或首次玩家盲测。其余七条梦想、五类普通职业留在后续阶段。未提交 Git。
