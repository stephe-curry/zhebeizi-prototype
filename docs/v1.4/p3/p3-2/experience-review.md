# 开发者体验审阅

审阅材料为 320×568 Chrome 正式入口的操作、截图和已提交事实。可确认操控、反馈和因果；首次玩家是否会主动发现手记、是否愿意重复训练，仍需真人盲测。

| 工作台 | 玩家当下看到和做的事 | 即时反馈与以后认得出的事 |
| --- | --- | --- |
| 电竞 | 录像中侧翼空缺，选留观察位或让替补换防。正式地区赛可以自己上场或在场边记换防 | 两种战术留下不同反馈。场边记录不能充当个人出场单。世界赛报名前还要对照合同、邀请赛成绩和出场记录 |
| 校园 | 给错误的等式补定义域，或把两个根都抄上答题卡。入学后以实验样例复核新方案 | 未排除的无效根会影响十八岁第一志愿。录取后同一本实验记录要在课程项目和毕业答辩中再次使用 |
| 房间 | 在河街与里巷之间试走，比较首期、押金及早班通勤。签约后能摆椅子，或者把真实旧物放在桌角或抽屉 | 房间显示现住所与仍持有的布置。换钥匙以后需要重新布置和维修；同一处住满年限才能认出旧窗 |
| 办公室 | 原报销样单圈对成本中心，才能做跨部门流转单。下一组实际处理第二张票时发现少一处签收 | 玩家补回执联，后来的交接材料就有两次真实工作的来源。撤岗与主动离开均保留这些文件 |
| 工位 | 比对 B8 工单和公用工具，缺件先挂标记。经培训核验后读同批两次尺寸，决定盖章还是隔离 | 选择不符工具或给超差件盖章会得到纠错反馈。复检合格和新人带教各有单独收据。坐式半班减轻负担，也减少工资 |
| 街区 | 对 HS-17 依次做等餐沟通、蓝签取餐、东巷绕行和侧门签收。出餐前不能把餐记作已取 | 错签可重选。送达播放蓝签落在餐盒上的逐帧动画，退回只付路费。以后书店认人要有真实交付回执 |

手记初版把选中的工作台放在所有路线按钮之后，小屏上要再次翻找。现将已选工作台移到手记开头，并在选择后滚动到操作位置。六组工作台分别绘制战术板、错题册、窗台、流转单、卡尺和街区图。每组四帧，140／100／120／280 毫秒；减少动态效果和用户关闭动画时显示末帧。配送签收另用八帧、900 毫秒一次播放。
