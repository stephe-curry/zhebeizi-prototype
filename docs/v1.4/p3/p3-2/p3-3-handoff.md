# 下一阶段的七条梦想

保留现有事实链。新增路线从真实接触开始，通过专属工作台操作记录参与、准备、核验和结果。多步骤场景可声明 steps，错误尝试留在草稿。专业工作或许可以贡献给两个目标，但须引用同一来源。收入、资产与机会一律由正式结算写入。

| 方向 | 可复用 | 尚需制作及核验 |
| --- | --- | --- |
| 02 跨栏奥运 | 电竞的赛事届次、报名、本人上场与有界外因；制造的工作负荷取舍 | 田径专项训练、达标成绩、协会选拔、赛会资格及恢复；保留奥运专属寄语 |
| 07 开源 | 校园项目与办公室交接的实际作品来源 | 代码贡献、项目维护、许可证与上游使用。J05 程序员需要先有正式聘约、真实开发工作及雇主作品权属 |
| 08 外科 | 学制门槛、监督学习、权限与复核 | 医学课程、临床实习、考试、注册、规培、岗位授权及聘任。外科医生职业身份必须能独立出勤和结算 |
| 11 原创歌手 | 分段排练、场地与参加记录 | 原创作品权属、演出、实际观众规模与合法演艺工作 |
| 12 演员 | 试训、入队和正式参与分别核验的结构 | 试镜、角色、真实演职员表、参评资格与对应奖项 |
| 25 乡村教师 | 真实认识与多年回访、职业转向 | J08 教师的资格、普通聘约、备课和课堂先成立，再做赴乡任教与学生回响 |
| 30 环游世界 | 地点比较、路线、资金与生活材料 | 真实行程、证件与地区限制、停留成本、目的地经历及回国后的生活 |

可编辑素材在 art，运行图集在 assets。六种工作台的图层独立，名称、时序、帧范围在 life-desks.json。需要新专业物件时按实际场景补绘。不要把工位的读数授权拿来授予医疗权限，也不要把真实独游发布自动投影为开源成果。
