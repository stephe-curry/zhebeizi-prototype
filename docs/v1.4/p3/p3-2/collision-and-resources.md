| 办公室＋成年备考 | 整班占两段，不能额外复习。签半班后，本期工资由 300 降至 150；报名与考试另付 30、60 元。正式入学交还原岗位。年龄差、实际课程、项目与答辩共同决定毕业 |

| 配送＋安家 | 实际送达的人再走街区时，选址收据能引用当年的订单。未送达没有老客回响。送过河街不足以生成一次入住 |
| 制造／配送＋学习 | 三类普通岗位均可改整班、半班、停薪或请假。整班与课外行动竞争时间，停班不能提交当班生产或配送工作。读研案例从制造岗位起步，办理全日制入学后停止原岗位收入 |
| 普通职业＋家庭 | 原主选择、家庭视角、支援、日程余段和旧短行动仍由同一事务预检。正式岗位内的任务可以属于当天主事；相同投入不会因两个投影再结算一次 |
