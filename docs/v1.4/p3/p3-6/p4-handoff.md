# P4 直接交接

先复跑本阶段 tests-and-browser.md。视觉修改后仍要验证工资、来源、时间、草稿与分叉，保持现有选择 ID。

优先整理手记中的主事与独立活动。展示当前位置、资格来源、时间、精力、现款及已签房租。玩家应在提交前理解为什么不能同时做两件事。暂停与达成的多梦状态需和具体作品、考试日期相连。

统一十八路线工作台的字体、像素缩放、边框与焦点。320×568 下核对长文本、底部提交按钮和弹窗滚动。减少动态效果要有可读完成帧，音效不得遮盖结算反馈。现有四帧封账源文件可继续编辑，避免重复结算时重复播报收益。

回忆录已有按来源连接的动作，可继续缩短重复文本并突出具体人、物件、作品和住处。不能将候选写成确立梦想，不能将预订写成到访，不能给失败者补奖。

真人初见仍需验证手记入口、两段日程、工资和服务费区别、暂停后去哪重拾。实体 Safari、Android 与真实游玩时长尚未验证，交 P5 安排并保留实测记录。
