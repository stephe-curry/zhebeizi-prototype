# 《这辈子》v1.4 · P3-1 交付报告

从正式页面开始，玩家可以在校赛报名后记下电竞梦，在做错题或成年咨询后记下清北梦，也可以一路不写。已记下的两条梦想分别追踪，在办公室改签半班、停薪学习或离岗时继续保留。46 槽实测中，整班玩家想抽时间复习会看到冲突；改签后去问硕士报考条件，当期保留半班收入。

## 工程交付

| 位置 | 本阶段改动 |
| --- | --- |
| routes.js | 轻量注册、专属方法和参与窗口；候选、梦想、聘约及资格均可按来源重建；含 01、03、J01 三份正式声明 |
| engine.js | 统一预览与原子提交、两段容量、现金试算、单一工资结算、确定性检验接线；保留未选择新内容时的原随机序列 |
| app.js、index.html、style.css | 场景中的手记、来源与成本、方法选择、冲突、工资、回忆录与动效；浏览器和 Node 共用声明 |
| save.js | 沿用外层 v2，按前缀重算动作、费用、结果及工资；恢复草稿，配置失效时保留既有事实 |
| art、assets | 分层 Aseprite 原画、透明图集、逐帧 JSON 和 4 倍 GIF。32×32 原画用 8 帧表现落笔、拖线、提笔及停顿，总长 900 毫秒。原画与笔各自分层，页面按整数倍显示，减少动画时展示末帧 |
| tests | 新增专项与真实 Chrome 走测；P2 回归支持指定证据目录，共用原正式页面操作助手 |

沿用工作树中的 P0–P3-0 成果，起点为 main 的 3ce57a2。此轮没有提交 Git。

## 验收与交付范围

- 原 acceptance、lifecycle、74 个旧 Node 子测试通过，新 Node 16 项通过，覆盖 M01–M12、E01–E05。两条正式梦想同时存在、曾暂停或放下的经历可查，测试专用路线未进入正式页面。
- Chrome 走完双梦想 46 槽并从第 23 槽分支。原 P2 复验覆盖 86 个 S/A 场景、126 个可玩短行动和 144 次可见阅读。实际截图、步骤与逐槽收据收录在测试报告中。
- 新制作的目标内容止于电竞接触、复盘与阶段测评，清北接触、两类成年咨询与复习，以及办公室聘约和工资适配。完整电竞生涯、清北招生与毕业、安家及其余路线按照 P3-2 至 P3-4 施工图继续制作。
- 校验对象为本机 Chrome 和模拟竖屏设备。没有进行 iOS Safari 或 Android 真机测试。已发布路线撤下时应保留历史规则解释器，以支持旧备份导入。
