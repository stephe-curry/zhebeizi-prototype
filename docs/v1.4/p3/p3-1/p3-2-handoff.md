# P3-2 制作交接

| 路线 | 现有接点 | 下一次开发应制作和验证的内容 |
| --- | --- | --- |
| 01 电竞 | 校赛报名、试训、录像报点、24/32 配合测评；原电竞队约与世界赛 | 分开记录公开试训、位置考核、短约、参赛与名次。用不同场次记录准备。验证办公室转入、暂停后赛历失效、未获队约后的普通工作。 |
| 03 清北 | 错题、考场、遮答案验算、24–29 槽本科或硕士咨询 | 分别制作本科报名与研究生报考资格，接入考试、录取、入学、课业及毕业事实。以实际年龄差与完成课程核验学制；咨询单只能作为接触。 |
| 29 安家 | 原租住、搬家、收拾和旧物事实 | 制作看房、合同或安置预算、选择地点及居住回访。先核验个人可支配款、合法债务与居住来源，再开放确立入口。 |
| J01 办公室 | 岗位身份、报销样单、四种出勤安排、调整和职业交接 | 增加工单、同事反馈、转组或再聘，按真实职责核验成果。半班和停薪边界已可复用。 |
| J02 制造 | 原制造岗位、量具与工作交接 | 制作工序、质量检验和安全培训。让已检样品成为后续班组任务的来源，再注册岗位工资。 |
| J03 配送 | 原入职、辨路、雨天、短班及调度 | 制作实际交接和路线选择，区分伤后恢复、普通短班与调度聘任。调度工资只能从当期有效聘约发放。 |

## P3-3 与 P3-4 可直接复用的部分

02 跨栏、07 开源、08 外科以接触、不同专业投入、资格来源和届次作为共享接点。专业方还要制作成绩与赛会门槛、真实代码贡献与许可、医学教育与执业资格。11 歌手、12 演员、25 乡村教师、30 旅行可复用多梦想状态、窗口、有成本行动及回响来源，分别制作原创作品和观众、角色和奖项、真实课堂和学生、真实行程与资源。

J04 小微经营、J05 程序员、J06 公务员、J07 厨师、J08 教师可使用主岗位、聘约、个人资金、工资来源及跨目标工作成果引用。经营流水、录用考试、厨房或课堂等专业内容仍需各自制作。两段都被主事占用时，应安排专属主场景或提供可负担的后窗。跨年学制、重大借款和新的薪资模型要单独设计持久事实，不能塞进一次短行动。

每条候选路线继续使用 P3-0 的来源表、六身份入口、46 槽机会压力表及完整路线施工图。开放前复跑本阶段扩展测试、旧竞争种子和真实页面；只有专业内容、成果及未竟路径均可实际走通才更新该路线的完成状态。
