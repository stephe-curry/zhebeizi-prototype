## Chrome 实际操作

三个套件都从本地正式 index.html 启动。P3 走测点「开始人生」，从第一个场景玩到第 46 槽；只在出生时固定种子。P2 同时有完整人生与合法存档前缀恢复，用于逐个职业和竞争场景复验。

| 操作 | 页面及正式事实 |
| --- | --- |
| 槽 7 写错题、槽 8 打开手记 | 出现带来源的清北候选，直接继续；测试路线入口不存在 |
| 槽 11 报校赛，槽 12 键盘记下电竞梦 | 刷新并恢复人生，草稿保留；确认后首次确立 |
| 槽 13 记下清北梦 | 双目标并行，正式确认显示手记动画 |
| 槽 14 主事加两项支援再选复盘 | 显示精力不足并禁用确认。撤回支援，键盘选择「等对手露面再报点」，正式事实保存 after |
| 槽 15、16 搁置和重拾电竞 | 清北保持 active，先前复盘仍可追溯 |
| 槽 23 就业，24 签整班，25 试着复习 | 明示时间排满。撤回、改签半班，本槽只发 150 元 |
| 槽 26 桌面鼠标参加硕士咨询，27 复习 | 正式接触引用咨询动作。系统减少动态效果时结算图停在末帧 |
| 槽 46 完成人生，从回忆录分支 | 分叉前的正式事实与父人生完整前缀一致 |
| 单独运行原 P2 | 完整无正式梦想人生、关键双约竞争、短行动与延期续接均可玩 |

布局覆盖 320×568、360×640、390×844、430×932、1366×768。校验包含横向溢出、底部操作区、模拟触摸、键盘、鼠标、减少动画和草稿恢复。普通 Chrome 套件一轮并发运行曾在餐桌翻页等待超时，独立重跑通过。最终验收命令按顺序启动各浏览器。
