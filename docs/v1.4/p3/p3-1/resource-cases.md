## 办公室同槽工资对照

M07 从同一实际进办公室的第 24 槽复制四份人生，主选择一致。未改签的对照组沿用原 300 元。下表仅列岗位工资，主选择的其他变化另行结算。

| 选择 | 本槽工资 | 与对照差额 | 后续排班 |
| --- | ---: | ---: | --- |
| 整班 | 300 | 0 | 两段出勤，余段不能再复习 |
| 档案室半班聘约 | 150 | −150 | 一段出勤；签约当期另花一段交接 |
| 离岗 | 0 | −300 | 保留职业经历，当前岗位停薪 |
| 停薪学习 | 0 | −300 | 当期不发薪，学习投入仍需另做 |

每个适配槽只有一份 pay，来源如 office-24。整班、半班、离岗和停薪学习共享发薪位置。半班收入替代原工资，履历中的历史岗位无法触发工资。旧职业和未改签的办公室沿用旧结算。结算后的再次确认返回 false。M06 对拒绝前后的整个 run 做深比较，覆盖金钱、随机历史、草稿、工资与物件。
