# 电竞配合测评

第 24、32 槽各自提供一期配合测评。参加消耗一段时间、一点精力和 50 元。两次真实投入作为本示例的资格门槛。零次投入即使把 skill 提至 100，结果仍为「资格不足」。接触校赛、记下梦想或阅读手记均不产生训练记录。

有资格后，本期测评按投入次数加本届外因判定，达到 3 才通过。这个门槛只用于校队配合测评。具体职业、招生和世界赛会分别声明专业判定。未通过时玩家保留录像和投入历史，可以继续训练。

| 第 24 槽种子 | 固定外因 | 两次真实投入 | 三次真实投入 |
| ---: | ---: | --- | --- |
| 1 | 0 | 本次未通过 | 通过 |
| 2 | −2 | 本次未通过 | 本次未通过 |
| 3 | +1 | 通过 | 通过 |

M08 通过完整人生前缀生成 18 组对照。M09 在确认前恢复存档，逐字段比较准备来源、资格来源、外因输入、结果与费用。确认后再点不会创建第二张收据。修改导入结果为冠军、更换路线、删去来源或改低成本都会被拒绝。另有测试专属朗读路线使用自己的样卷核验资格，经实际资格动作后参加固定届次，验证完成状态与导入重建。
