# 职业现场与活动密度

|职业|可操作的判断|中年变化与长期来源|
|---|---|---|
|经营|帮摊找零，选择场所与经营方式、横线或方格本、售价，退款与盘货|第30槽后可调整货量、停业重开；第41槽阿棠按旧购货单回头|
|程序员|区分空值、0、字符串0；错误转换不能过测试；选择灰度或回滚|第31、35槽现场维护，撤岗与再聘；第42槽新人保留旧兼容样例|
|公务员|补正路口位置，权限内转交，紧急件与常规材料分工|第33槽回执查询，第36槽换职责，第42槽查公开通道验收|
|厨师|核原料、生熟工具、火候、桌号与少盐单；退菜后重做|第30槽晚高峰分工，第34槽带小许，第38槽换店，第42槽熟客认菜|
|教师|具体进位错因、小棒演示、按人批作业与家校约定|第33槽新班册，第36槽共同教研，第42槽旧学生拿出示范卡|

每项手记活动从当前生活页进入具名职业场所，完成方法和步骤后返回当期安排，再统一提交。五职业共享原生弹窗、日程和事实机制，场景任务各自不同。普通工作线在青年、中年和较晚人生均有可用动作。

开发者走测可以确认文本反馈、按钮、来源和结算。首次理解和乐趣尚需真人体验。原J01–J03仍主要保留旧主事件与已有手记，30–40槽的跨职业密度比较留给P3-5继续检查。
