# 制度参照与游戏假设

核验日期为2026-11-19。人物生活年代的具体岗位、空缺、报考表、摊位许可和食品检查结果均采用游戏推演。实际法律依据只用于约束硬门槛。

- 公务员采用2026年度公告的普通年龄与学历框架。故事选择本科、不限专业的虚构街道综合服务岗。报名、笔试、面试及体检考察公示、录用报到分别保留。未来真实岗位尚未公布。实际行政审批由有权部门完成，玩家只受理、转交和追踪。[2026年度公告](https://www.forestry.gov.cn/c/www/gsgg/645380.jhtml)
- 指定场所、指定时间的日常用品经营适用特别规定；无固定场所摊贩管理另有地方规则。本作选择普通文具，开摊动作合并场所和经营核验。没有给所有摊贩设统一食品许可证。[无证无照经营查处办法](https://xzfg.moj.gov.cn/front/law/detail?LawID=429) · [市场主体登记条例](https://www.samr.gov.cn/djzcj/zyfb/zjfb/art/2023/art_2a71fe3f890947e4860918946cb60386.html)
- 饭馆承担经营许可、原料查验和员工健康管理。学徒需入岗核验，生熟工具分开，原料不足不得记已出菜，退回菜品按制度弃置后重做。本作没有模拟专业烹饪培训。[食品经营许可和备案管理办法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_91a91c26ae464a2f898952d5b84f62c6.html)
- 教师沿用P3-3的本科、资格认定、招聘和具体学校聘任。返岗核验资格与试教；学生按班级区分，课外志愿经历不授正式权限。[既有专业规则](../p3-3/professional-rules.md)
- 软件雇佣项目、个人项目和授权公共适配器沿用既有权利人。大型企业岗位属于虚构招聘，仅取得真实交付和维护经验者可申请；竞争结果有界，录取与求职分开。
