# P3-5 交汇与连续性

- 对十梦想与八职业建立同前缀对照，尤其检查多梦想、整班工作、家庭照护与住处变更叠加。
- 成年备考和全日制培养仍需检查已任职身份的退出、重新求职与资格年度，未来公务员职位表不能当现实公告。
- 30–40槽五种新职业已有具体维护、办件、带徒、教研和经营变更。J01–J03要用同一指标比较，避免主要依赖工资记录。
- 梦想高光后应继续读当前岗位、学生与作品来源；离岗不会删除原人物和作品。
- J04已有厨师转自营食堂的许可核验、场地费、独立食材库存和实际交付收入。P3-5需补餐饮停业清算、更多食材损耗和家庭资金长期对照。
- 后续增加公务员跨年度考试失利后恢复、程序员大型企业岗位的日常责任和长期回响见证。
- P3-6需全量旧档样本、同前缀分叉对比、多设备真人初见和关键机会竞争复验。回忆录引用正式收据，勿用职业名推测成果。
