## 正式游戏的修改

|位置|修改内容|
|---|---|
|`content.js`、`responses.js`|将 P0 等级接到正式卡配置，补同窗日程、真实来源约束、后续动作、即时反馈、职业样单、旧物和终章变体。短行动只占当前回合的一点精力，也可以留空。|
|`engine.js`、`continuity.js`|继续使用同一事实日志和 `E.commit()`。竞争按当前资格可改约，晚年旧文件有第 45→46 槽合法续接。记录是否看到、是否实际投入、是否形成作品或成绩，并能回查对应选择。|
|`app.js`、`style.css`、`index.html`|正式页加入两处约的选择、在场的物件检查、来源明确的短行动以及像素反馈。草稿可撤回，物件位置和当前归属对应，曝光依据实际视口。|
|`save.js` 及现有交互、场景入口|在已有兼容结构中检查日程草稿和候选；旧人生仍能继续。复用已有日程、饭桌、工作台、搬家和人物道具机制。|
|`art/`、`assets/`|用 Aseprite 制作并导出可编辑分层原稿、透明 PNG 图集、带逐帧时长与标签的 JSON，以及预览。包含日程盖章和单据、套筒、绕路图三个岗位动作，减少动画时显示静态结果。|
|`tests/`、`docs/v1.4/`|新增路径复演、来源对照、浏览器复演和 P2 导出。原验收、童年、引导页、浏览器等测试接受新的真实剧情预期。保留原有测试及 P0/P1 产物。|

## 玩家能感受到的变化

- 425 的 35 岁当晚可去决赛或处理发行。立即交一个准备不足的项目会失败，修整后交才发布，留在赛场退役也能继续生活。474 的 64 岁要在办公室与旧队伍间选一处，到 72 岁还得亲手打开旧文件才有截图。其他四种岗位与旧文件同窗、配送两种班次也有实走对照。[同窗的决定与后果](opportunity-collisions.md)
- 旧友发来的新纸只在真一起讲过题时才带有共同记忆。给出了工牌的人只能抄号码，没参加过训练的人不会获得比赛履历。留岗、调整、休息在 38 岁及实际继续后的 64 岁各有不同的行动。错过、放下或失去物件都能继续生活。[前情与物件修复](content-fixes.md)
- 玩家可以找出报销单漏填的栏、核对工具板空钩、在配送图标出绕行线路。看错可重试，正确标记且确认对应工作才留下以后能教人的具体作品。逐卡体验表记录动机、操作、现场反馈和体验判断。[逐场体验审阅](experience-review.md)
