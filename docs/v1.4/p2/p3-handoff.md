## 接线和验收

1. 先在正式事件给玩家一个能操作的具体动作，通过 `E.commit()` 保存来源、对象和结果。沿用 `LifeContinuity.evidence/growth/thread` 查证据。学习、现金、职业或一次接触各只能证明自己。
2. 再决定后续是占一段完整时间、使用一点余力，还是只在物件或场景留下可辨认的变化。跨槽需要明确 `opportunityWindow` 和当期资格；可参考第 45→46 槽文件续接。
3. 人物要核实见面、联系和存活状态，私人旧物要核实去向。加入同一回合的互斥机会后，分别走一次选择、放下或失去资格，并复查回忆录。
4. 保留六至十三岁各版交互、旧饭桌、物件履历、普通结尾、合法提前谢幕与人生树隔离。沿用现有测试，并为七条线补上各自具有不同投入和结果的正式游戏走测。
